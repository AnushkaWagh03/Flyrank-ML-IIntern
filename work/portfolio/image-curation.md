# Image Curation — FlyRank ML Internship Portfolio

## Purpose

This image set supports my portfolio case study for the FlyRank ML Internship. My goal was to use visuals as evidence of the work rather than decoration. Most images are real captures from my repository, notebooks, and analysis outputs.

## Where I Chose Real Captures Over AI

For the core project visuals, I deliberately chose real screenshots instead of AI-generated images.

The FlyRank ML Internship work involves notebooks, data analysis, prompt iteration, and technical outputs. An AI-generated illustration of data science or machine learning could look visually polished, but it would not prove that I actually performed the work.

Real captures provide stronger evidence because they show:

* The actual repository and project structure
* My notebook-based analysis
* Real outputs and findings
* The prompt iteration process
* The final recommendations produced from the work

For this case study, authenticity is more valuable than decorative visuals.

---

## Generated Visuals

I considered using AI-generated visuals only for connective elements such as subtle background textures or abstract section illustrations.

The visual direction would be:

> Minimal, editorial, technical, calm, and analytical. Soft abstract data patterns, subtle grid structures, restrained composition, and a clean modern research aesthetic. No futuristic robots, glowing brains, or generic AI imagery.

I would keep any generated visual secondary to the actual project evidence.

---

## Generated Image Rejected

I rejected a generic AI-generated image showing a glowing human brain connected to floating data dashboards.

Although the image looked visually impressive, it was too generic and could represent almost any AI or machine learning project. It did not provide evidence of my specific FlyRank work and created a more promotional than analytical tone.

I chose real notebook and repository captures instead because they communicate the actual process and decisions behind the project.

---

## Curation Decision

The final set prioritizes evidence over decoration.

The screenshots were selected because each one supports a specific part of the case study:

**Repository → Proof of project**

**Research notebook → Problem framing**

**Data analysis → Investigation**

**Prompt iteration → Decision-making process**

**Final output → Results and recommendations**

This creates a visual narrative that follows the actual workflow rather than presenting unrelated images.
